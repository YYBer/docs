Whether you want to swap tokens in seconds, place precise limit orders, trade perpetual futures through Hyperliquid, monitor other wallets, or connect a custom trading bot via the REST API and TypeScript SDK — Fibe brings it all together in one platform.

## Platform Architecture

Fibe is built as two complementary layers that work together — a consumer-facing UI for everyday trading, and a developer-facing API layer for programmatic access.

### Consumer Interface

The Fibe web app gives you a full-featured trading dashboard: live orderbooks, candle charts, portfolio views, wallet tracking, and perpetuals trading — all accessible through your connected Solana wallet. No account registration with a custodian is required; every action is signed by your wallet and settled on-chain.

### Developer and API Layer

For developers and algorithmic traders, Fibe exposes two distinct components:

**Info API (REST)**
The Info API provides read-only access to all market data over standard HTTP. You can fetch current markets, orderbooks, recent trades, historical candles, and live user orders — no authentication required. The base URL is `https://api.fibe.com`.

**Exchange Client (On-chain)**
Trading operations — placing, modifying, and cancelling orders — are executed directly on the Solana blockchain through the Fibe smart contract. These actions require a Solana wallet to sign each transaction. The TypeScript SDK's `ExchangeClient` handles transaction construction and submission for you, so you can focus on strategy logic rather than low-level Solana plumbing.
